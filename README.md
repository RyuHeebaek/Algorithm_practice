## 🏷️ 파일 이름 규칙

| 플랫폼 | 규칙 | 예시 |
| :--- | :--- | :--- |
| BOJ | `BOJ_<문제번호>.java` (문제 폴더 `<번호>. <제목>/`) | `BOJ/Gold/9663. N－Queen/BOJ_9663.java` |
| Programmers | `PG_<문제번호>.java` (문제 폴더 `<번호>. <제목>/`) | `Programmers/Lv1/12977. 소수 만들기/PG_12977.java` |
| SWEA | `SWEA_<문제번호>.java`, 다른 풀이는 `_v2`, `_v3` | `SWEA/D3/SWEA_6808_v2.java` |
| CodeTree | `CodeTree_<코스>_<번호>.java`, Trail2는 내보낸 파일명 유지 | `CodeTree/Chapter/CodeTree_Chap_4_1.java` |

- 클래스 이름은 항상 파일 이름과 같습니다(`public class BOJ_9663`). 폴더째 받아 IntelliJ에서 파일을 바로 실행할 수 있게 하기 위해서입니다.
- 제출할 때는 각 플랫폼이 요구하는 클래스명(`Main`, `Solution`)으로 바꿉니다. 모든 파일이 `package` 없이 단일 클래스로 끝나도록 유지합니다.

## ▶️ 실행

1. IntelliJ IDEA에서 저장소를 열고 실행할 파일을 고릅니다.
2. `main` 메서드를 실행하고 문제의 입력을 넣습니다.
3. 모든 `.java` 파일은 `javac` 기준 문법 검사를 통과합니다(2026-11-20, JDK 21).
